# Kin Arc design system

The interface is an archival map-room workspace: the chart is the field, navigation is quiet, and country color is the primary analytic layer.

## Principles

- Keep the fan chart visually dominant.
- Treat empty ancestor segments as meaningful data, not missing UI.
- Use country color consistently in the fan, legend, editor, and details.
- Prefer familiar form controls and explicit privacy language.
- Preserve calm density for long research sessions.

## Tokens

- Ground: `#f3efe4`; raised paper: `#fbf9f3`; workspace: `#e9e4d7`.
- Ink: `#202923`; secondary ink: `#535e57`; rule: `#d7d1c2`.
- Action green: `#173d33`; focus/risk accent: `#b65338`.
- Display type: Newsreader. Interface type: DM Sans.
- Control radius: 9px; raised surface radius: 12–15px.
- Elevation: soft, downward, neutral shadow only for floating details and dialogs.

## Signature interaction

The semicircular ancestor field reads like a geographic atlas plate. Country colors form continuous migration patterns across branches, while dashed paper-white wedges keep unrecorded ancestors structurally visible.

## Responsive behavior

Desktop uses a fixed control rail and large chart field. Tablet narrows the rail. Mobile places controls above a minimum-height chart and turns ancestor details into a bottom sheet.
